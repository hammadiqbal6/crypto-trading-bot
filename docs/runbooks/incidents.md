# Runbook: Incidents

1. **Pause** — toggle bot flag off; stop freqtrade process.
2. **Assess risk** — kill switch, open positions, exchange status.
3. **Preserve logs** — `user_data/logs/`, dashboard log panel.
4. **Do not** enable live while remediating.
5. File notes in CHANGELOG / issue with timestamps and guidance shown to users.
